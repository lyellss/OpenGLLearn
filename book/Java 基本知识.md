
### 字节（Byte）基础知识

- 字节（Byte）是计算机存储的基本单位
- 1字节 = 8位（bit）
- 1位就是一个二进制数（0或1）

### Java 基本数据类型详解

1. **整数类型**：
    - `byte`
        - 1字节（8位）
        - 范围：-128 到 127
        - 常用于处理小范围整数，节省内存

    - `short`
        - 2字节（16位）
        - 范围：-32,768 到 32,767
        - 用于较小范围整数运算

    - `int`
        - 4字节（32位）
        - 范围：-2^31 到 2^31-1
        - 最常用的整数类型

    - `long`
        - 8字节（64位）
        - 范围：-2^63 到 2^63-1
        - 用于大数值计算

2. **浮点类型**：
    - `float`
        - 4字节（32位）
        - 精度：6-7位有效数字
        - 用于需要小数但精度要求不高的场景

    - `double`
        - 8字节（64位）
        - 精度：15-17位有效数字
        - 浮点运算的默认类型

3. **字符类型**：
    - `char`
        - 2字节（16位）
        - 存储单个字符
        - 使用 Unicode 编码

4. **布尔类型**：
    - `boolean`
        - 1位
        - 只有 true/false 两个值
        - 用于逻辑判断

### 精度说明

精度指的是数据的准确度：

1. 整数类型：精度体现在数值范围上
2. 浮点类型：精度体现在小数点后的有效位数
    - 例如：float 的 1.23456789 可能会被约为 1.234568
    - double 的精度更高，更适合精确计算

### 实际应用示例

```java
// 整数类型
byte age = 25;          // 存储年龄
short year = 2023;      // 存储年份
int population = 1400000000;  // 存储人口数
long distance = 149600000L;   // 存储天文距离（单位：公里）

// 浮点类型
float price = 19.99f;   // 存储商品价格
double pi = 3.141592653589793;  // 存储高精度数学常数

// 字符类型
char grade = 'A';       // 存储等级

// 布尔类型
boolean isActive = true;  // 存储状态
```

### 选择建议

1. 一般整数运算用 `int`
2. 需要小数计算，优先用 `double`
3. 对内存特别敏感时，选择合适范围的最小类型
4. 处理货币时，使用 `BigDecimal` 类，避免浮点误差
